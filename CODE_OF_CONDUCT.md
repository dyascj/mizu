# Code of conduct

Mizu is committed to a respectful, useful, and safe contributor community.

## Expected behavior

- Be clear, patient, and constructive.
- Critique ideas and code without attacking people.
- Respect differing experience levels, identities, and communication styles.
- Keep review feedback specific and actionable.
- Give credit and protect private or security-sensitive information.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate intimidation, doxxing, sustained disruption, and publishing private information without permission are not accepted in project spaces.

## Scope and enforcement

This policy applies in issues, pull requests, discussions, release spaces, and project-related private communication. Maintainers may edit or remove content, close interactions, temporarily restrict participation, or permanently ban a participant when needed to protect the community.

Report urgent platform abuse through [GitHub's abuse reporting tools](https://support.github.com/contact/report-abuse). For a sensitive project report that should not be public, contact the maintainer through the repository owner's GitHub profile and clearly label the message as a code of conduct report. Reports will be handled as privately as practical, with conflicts of interest disclosed.

Good-faith disagreement is welcome. Retaliation against someone who reports a concern is not.
