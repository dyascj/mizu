# Support

Mizu is maintained as an open-source component registry.

## Where to ask

- Use a bug report when documented behavior fails in a supported SvelteKit project.
- Use a component request for a focused addition to the catalog.
- Use the accessibility template for keyboard, focus, announcement, semantics, contrast, or motion concerns.
- Use the documentation template for missing, incorrect, or unclear guidance.
- Use [GitHub private vulnerability reporting](https://github.com/dyascj/mizu/security/advisories/new) for security concerns.

Include a minimal reproduction, the exact pinned Mizu registry version, Node and pnpm versions, browser or assistive technology where relevant, and the result you expected.

## Support boundaries

The supported toolchain is documented in `package.json` and `docs/decisions/0004-support-policy.md`. Help is best-effort. The project does not promise implementation dates, private integration consulting, or support for modified component source.

Questions that can help multiple users should remain in public issues. Do not include secrets, customer data, private source, or unpublished vulnerability details.
